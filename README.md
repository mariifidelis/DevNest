DEVNEST

#Processo de Ideação

A ideia do DevNest surgiu a partir da necessidade de facilitar a conexão entre profissionais da área de tecnologia e oportunidades de trabalho freelancer.

Muitos estudantes e profissionais iniciantes possuem conhecimentos técnicos, mas encontram dificuldades para conseguir seus primeiros projetos e experiências profissionais.

Pensando nisso, foi criada a ideia de uma plataforma onde freelancers da área de tecnologia podem:

- Visualizar projetos disponíveis;
- Analisar os requisitos de cada projeto;
- Ver o orçamento e o prazo;
- Enviar propostas para clientes;
- Acompanhar suas propostas;
- Visualizar contratos;
- Confirmar o fechamento de um contrato.

O nome **DevNest** representa a ideia de um espaço para desenvolvedores crescerem profissionalmente, encontrarem oportunidades e construírem sua trajetória na área de tecnologia.

#Protótipo Inicial

O design inicial do projeto foi desenvolvido seguindo uma proposta minimalista.

As principais características do protótipo são:

- Uso das cores azul, branco, preto e tons de roxo;
- Layout simples e organizado;
- Interface minimalista;
- Fotografias em preto e branco na página inicial;
- Elementos visuais inspirados em um wireframe inicial;
- Navegação simples entre as páginas.


#Funcionalidades do Sistema

O DevNest possui as seguintes páginas:

#Home

Página inicial da plataforma.

Possui um mosaico de imagens que representa visualmente o universo da tecnologia e do trabalho freelancer.

#Login

Permite que o usuário acesse a plataforma.

A página possui uma animação visual no fundo utilizando gradientes e animações CSS.

#Cadastro

Permite que novos freelancers criem uma conta na plataforma.

O formulário possui campos para informações como:

- Nome;
- Profissão;
- Área de atuação;
- E-mail;
- Telefone;
- Descrição profissional;
- Senha.

#Projetos Disponíveis

Nesta página, o freelancer pode visualizar projetos disponíveis.

Os projetos são organizados em cards contendo informações como:

- Área;
- Nome do projeto;
- Descrição;
- Valor.

Também existem filtros para diferentes categorias de projetos.

#Detalhes do Projeto

Permite visualizar informações mais completas sobre uma oportunidade.

São apresentados:

- Orçamento;
- Prazo;
- Área;
- Descrição;
- Requisitos;
- Tecnologias necessárias.

#Enviar Proposta

O freelancer pode enviar uma proposta para o projeto.
É possível informar:

- Valor;
- Prazo;
- Mensagem para o cliente.

#Minhas Propostas

Permite acompanhar as propostas enviadas.

Cada proposta pode apresentar um status, como:

- Em análise;
- Aceita.

#Contrato

Quando uma proposta é aceita, o freelancer pode visualizar as informações do contrato.

Para finalizar o processo, é necessário aceitar os termos antes de fechar o contrato.

#Contrato Fechado

Página exibida após a confirmação do contrato.
Para finalizar o processo, é necessário aceitar os termos antes de fechar o contrato.

#Contrato Fechado

Página exibida após a confirmação do contrato.

Apresenta as principais informações do projeto e confirma que o contrato está ativo.

#Perfil

Página destinada às informações do profissional freelancer.

#Sobre

Apresenta informações sobre a proposta e o objetivo do DevNest.
